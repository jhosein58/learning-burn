# Example 15.4 — A Small CNN as a Module

`SmallCnn` is conv(1→4) → ReLU → max-pool → conv(4→8) → ReLU → global average pool → linear(8→4). The data is 12x12 "shapes" (bars, diagonals, plus signs) generated by a tiny LCG that Rust and Python share bit for bit. The weights are set to fixed numbers so both frameworks start from the same model.

```rust
#[derive(Module, Debug)]
struct SmallCnn<B: Backend> {
    conv1: Conv2d<B>,
    pool: MaxPool2d,
    conv2: Conv2d<B>,
    gap: AdaptiveAvgPool2d,
    head: Linear<B>,
}
```

## Run & test

```bash
cargo run -- -c 15 -e 4 rust      # from the repo root
cargo run -- -c 15 -e 4 python
cargo test -p c15e4 --release     # the Rust parity test
pytest examples/chapter15/e04_cnn_module/python/main.py      # the Python parity test
```

## Parity

Same 16 logits as PyTorch to 1e-5. The CNN has **372** parameters. An MLP doing the same job (144 → 32 → 4) needs **4,772**: that difference is weight sharing.
