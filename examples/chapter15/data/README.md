# Chapter 15 data

`shakespeare.txt` is the first 199,994 bytes (7,552 lines, ending at a line break) of Tiny Shakespeare,
the text of several Shakespeare plays collected by Andrej Karpathy for char-rnn:
https://raw.githubusercontent.com/karpathy/char-rnn/master/data/tinyshakespeare/input.txt

Shakespeare's plays are in the public domain. The slice is plain ASCII with 62 distinct bytes.
Chapter 15 uses it in every example that reads text; Chapter 16 ships its own byte-identical copy of the same text.
