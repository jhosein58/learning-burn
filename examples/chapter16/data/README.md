# Chapter 16 data

`shakespeare.txt` is the first 199,994 characters (about 200 KB) of Tiny Shakespeare:
text by William Shakespeare, which is in the public domain, as collected by Andrej Karpathy
for char-rnn (`data/tinyshakespeare/input.txt` in https://github.com/karpathy/char-rnn).
It is plain ASCII with 62 distinct characters. Every Chapter 16 example reads it through a
relative path, so run them from anywhere in the repository.
